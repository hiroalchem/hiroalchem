# Hi there, I'm Hiroki Kawai 👋

I'm a Python developer and researcher passionate about **scientific image analysis** and **AI-powered annotation tools**. I build open-source plugins for [napari](https://napari.org/) — a multi-dimensional image viewer for Python — to make image analysis more accessible for scientists.

---

## 🔭 What I'm working on

- **[napari-SAM4IS](https://github.com/hiroalchem/napari-SAM4IS)** — napari plugin for instance & semantic segmentation using the Segment Anything Model (SAM). Supports SAM 1 & SAM 3, COCO format export, API mode, and hierarchical class management.
- **[napari-simpleannotate](https://github.com/hiroalchem/napari-simpleannotate)** — a lightweight annotation plugin for napari.
- **[napari-large-image-importer](https://github.com/hiroalchem/napari-large-image-importer)** — efficiently import large images into napari.
